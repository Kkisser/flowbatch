# База продуктов

Подпапка = продукт, внутри — его фотографии (jpg / jpeg / png / webp):

```
products/
  rl410/
    front.jpg
    side.jpg
  rl230/
    rl230.jpg
```

В промпте:

```
@product rl410            ← прикрепить ВСЕ фото продукта (по алфавиту)
@product rl410/front.jpg  ← прикрепить одно конкретное фото
```

При прогоне фото сами заливаются в текущий проект Flow — **один раз на
проект**, дальше берутся из кэша по uuid (`.flowbatch_refcache.json`).
Переписал файл фотографии — заливка повторится автоматически (кэш ключуется
путём + mtime + размером).

Посмотреть базу: `python -m flowbatch.cli products` или блок «База продуктов»
в веб-панели.

Сами фотографии в git не коммитятся (см. .gitignore) — это бинарные
бренд-активы; структура папок и этот README коммитятся.
