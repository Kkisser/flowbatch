# Папка промптов

Сюда складываются очереди задач — всё, что описывает, **что** генерировать.
Код программы лежит уровнем выше и этой папки не касается, кроме чтения.

## Что тут лежит

| Что | Откуда берётся |
|---|---|
| `<ИМЯ>.flow.txt`, `<ИМЯ>.txt` | твои файлы: сохрани сюда результат мета-промпта |
| `pasted_<N>.flow.txt` | панель сама пишет сюда текст, вставленный в прогон №N |
| `*.xlsx` | очереди из Excel (листы IMG_QUEUE / VID_QUEUE) |
| `*.yaml` | старый формат jobs.yaml |

`pasted_<N>.flow.txt` **перезаписывается** при каждой вставке текста в прогон
с этим номером. Хочешь сохранить очередь надолго — переименуй файл во
что-то осмысленное, например `MISS_ULYBKA_S01E02.flow.txt`.

## Как указать очередь в панели

В поле «очередь» достаточно **имени файла** — программа сама найдёт его здесь:

```
MISS_ULYBKA_S01E01.flow.txt
```

Полный путь тоже работает, если файл лежит где-то ещё. Панель подсказывает
список файлов этой папки выпадашкой — кликни по пустому полю.

Из командной строки так же:

```bash
.venv/Scripts/python -m flowbatch.cli run --prompts MISS_ULYBKA_S01E01.flow.txt
```

## Формат

Директивы (`@project`, `@use`, `@product`, `@duration`) описаны в
[PROMPT_FORMAT.md](../PROMPT_FORMAT.md). Мета-промпты, которыми эти файлы
генерируются, — [META_PROMPT.md](../META_PROMPT.md) и
[META_PROMPT_ZUBY.md](../META_PROMPT_ZUBY.md).

Папку можно переназвать в `config.yaml`: `paths.prompts_dir`.
